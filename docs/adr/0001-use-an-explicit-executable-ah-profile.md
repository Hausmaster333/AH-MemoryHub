# Use an explicit executable AH profile

The monograph is normative for the AH data structure but leaves several runtime details ambiguous and contains conflicting type notation. AH-MemoryHub therefore names and tests an `AH-2026-executable-v1` profile: it preserves `AH=<S,C,P,H,L>` and the mandatory operations while adding explicit Role Bindings, links to `S`, immutable edit identities, `editLink`, bounded runs, and a documented integration rule for incoming excitation. Literal monograph behaviour remains available as `literal_2026` for comparison, so extensions cannot be mistaken for the author's formulas.
