## Что изменилось

1. Явные записи «параметр — скаляр» восстанавливаются как HAS_STATE: часы, проценты и поддержанные единицы измерения. Отрицательная температура не становится IS-A. В конструкции «значение, а не отвергнутое значение» основное значение записано отдельно, вся исходная цитата сохранена. Это ограниченный разбор явных скаляров, не универсальный парсер событий/чисел.
2. Определение начала ACTION по окончаниям слов заменено установленным pymorphy3. «Сигнал» и «отдел» больше не считаются глаголами только из-за окончания «л». Проверены активные и пассивные фразы. Морфологическая неоднозначность всё ещё возможна.
3. Временной выбор HAS_STATE проверяет глагол события по морфологическим формам состояния/цитаты; учитываются причастия. Отдельный уже существующий путь длительности состояния сохранён. Не означает полной проверки привязки времени внутри многособытийной фразы.

## Оставшиеся дефекты и следующий шаг

Полнота критически низкая. В роли-ориентированном prompt явно запрещено утверждать отрицательные события, отдельное представление отрицания не реализовано. Полноценная обработка отрицательных вопросов требует согласованной семантики хранения и поиска, а не снятия одного guard.

Распределение некоторых восстановленных скалярных свойств по C/P/H остаётся эвристическим: например, «Правильное время инцидента» сейчас попадает в C без явного TIME. Корректное значение не равно завершённой семантической модели события. Нужно исправить этот слой с сохранением различия абстрактного свойства и эпизода.
