# Исполняемая спецификация активации

Основа: монография Душкина 2026, с. 48, 51–52. Проверка: `GET /api/v1/conformance/senior/activation` и `backend/tests/test_directed.py`.

## Профили

`directed_v1` распространяет сигнал только по направленным L и от N к актантам. `integrated_v1` сохраняет совместимость со старыми дампами: добавляет неявный актант→N, только если нет явной L между этой парой. `literal_2026` оставляет буквальное затухание x без интеграции входа. Профиль по умолчанию пока `integrated_v1`; направленный профиль выбирается в Params или запросом API.

Для двух интегрирующих профилей принята инженерная формула `x_next = clip(x + z) * exp(-lambda * dt)`. Это разрешение недоопределённости шага 5 книги, а не её дословная формула. Для буквального профиля `x_next = x * exp(-lambda * dt)`.

Выход `f(z,x)` хранится отдельно: `clip_sum=clip(x+z)`, `relu=clip(z)`, `sigmoid=1/(1+exp(-(x+z)))`. В начале запуска выход равен `f(0,x_initial)`; seed устанавливает x=1. На такте k все импульсы равны выходу источника предыдущего такта, умноженному на старый вес. Обновлённые веса используются со следующего такта. Для L принят `clip(w + eta*x_source*x_target)`, для N — `clip(w + eta*x_N*mean(x_actants))`, по уникальным актантам. Эти конкретные f/g/h — выбранные функции, книга допускает гиперпараметры.

Рабочая память: вход при x>t, выход при x<t, равенство сохраняет предыдущее членство. Ритмоводитель даёт начальный импульс на первом такте, далее частота определяется Hz и dt; нулевая частота отключает его. Без seeds выбирается первый S по UID. Фоновый цикл и перенос контекста между запросами не реализованы.

## Явные связи

Новый ingestion сохраняет `GROUNDS: S→C`, `EVOKES: C→S` и `RECALLS: actant→N` с весом `w_N / число уникальных актантов`. Направленные предметные CAUSE/FOLLOW/IS-A остаются отдельными связями. RECALLS означает обращение к уже сохранённому факту, а не доказательство истинности факта из наблюдения актанта. Старые дампы автоматически не мигрируют: для directed_v1 нужен повторный ingestion либо явно добавленные L.

Демонстрация на отдельной памяти задаёт S «Насос Н-17», C «Класс: насос», P «Модель насоса Н-17» и цикл S→C→P→S. Проверяются оба направления активации, устойчивость петли без ритмоводителя, затухание после удаления связей и автономная подпитка. Это демонстрация обобщения/конкретизации через существующие понятия; индуктивное обучение новым классам не заявляется. Демо не изменяет пользовательскую память.

## Следующая приёмка

1. Пересчитать M1 на свежем ingestion и закрыть оставшиеся ошибки ролей/идентичности.
2. Автоматически построить память из ≥15 000 слов, проверить размеры после GC и время такта при N≥1000.
3. Независимый M2 с отрицательными примерами; M4/M5 с настоящими AH/RAG и моделями.

Этот отчёт не является полной сертификацией Senior. Проверяемые формулы и малая демонстрация не подтверждают качество понимания текста или масштабируемость.
