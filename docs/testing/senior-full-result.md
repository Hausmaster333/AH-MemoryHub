30 отредактированных вымышленных документов, 15647 слов по прежнему счётчику (15330 по пробелам), 40 зафиксированных вопросов. Первые 12 вопросов уже служат регрессией; 28 новых были записаны до извлечения. Это не независимая слепая экспертиза и не завершённая приёмка Senior.

Локальная Qwen 2.5 7B Q5_K_M: 435 предсказаний, 434 приняты, одно отклонено из-за цикла IS-A. Первые пять документов воспроизведены из ранее сохранённых ответов, остальные обработаны локально. Ошибка обрезанного JSON устранена делением проблемного диапазона предложений; исходные неудачные записи сохранены.

Автоматический QA на общей памяти: исходно 17/40; после изменения распознавания исполнителя и устойчивого выбора поисковых символов — 18/40 (senior-full-qa-v8.json). Проверка требует точного совпадения ожидаемой цитаты, поэтому, например, правильный ответ с дополнительным маркером списка может не пройти её. Эталон ради результата не менялся.

Парный пилот senior-paired-v7 завершён: 80 ответов, одинаковая локальная модель, векторный RAG использует 417 фрагментов, окно96/перекрытие24/top4. В этом пилоте ещё старая сортировка равных поисковых оценок по случайным ID; исправление сортировки проверено отдельно. Все 80 ответов прошли проверку формата ссылок, но это не доказательство истинности.

Исправления этого этапа: CLI сохраняет отклонённые кандидаты и оценивает только принятую память; вопросы об исполнителе требуют совпадения действия; добавлена форма вопроса о собственнике; равные поисковые оценки сортируются по содержимому перед случайным ID. Внутренние операции изменения памяти копируют словари вместо глубокого копирования всей структуры; снимки продолжают глубоко копироваться, проверка инвариантов и откат сохранены. 102 теста прошли.
