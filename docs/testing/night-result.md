## Применённые изменения

- Канонизация CAUSE выделяет однозначные пространственные хвосты «внутри/снаружи», «на/у входе/выходе» в LOCATION, сохраняя цитату и границы события. Дополнения вроде «в резервный режим» не объявляются местом.
- Правило владения перестало захватывать «и содержит/включает…» в имя владельца. Корректные границы отдельных OBJECT не расширяются до всей цепочки свойств.
- Ошибочная самопривязка свойства в конструкции «X имеет Y» исправляется на явно названного владельца X; при «X имеет … и находится …» используется X из текущего предложения.
- Вопрос «Что вызвало остановку?» ищет причину указанного следствия, а не следующее следствие цепочки. «Какие инструменты…» попадает в поиск инструментов. Это проверено через API на отдельных примерах.
- Валидация строит общий словарь элементов один раз, а не заново для каждой ссылки. Проверки целостности сохранены.
- M2 больше не принимает одно присутствие UID в журнале за доказательство: проверяет рабочую память и замыкание зависимостей до seed. Искусственное удаление родителей трассы даёт 0 успешных случаев. Этот M2 явно помечен как activation fixture с заданной целью, а не полноценная проверка естественно-языкового QA.
