Добавлен необязательный `perception_format=roles`: значения ролей извлекаются непосредственно, без таблицы mentions. IR остаётся форматом по умолчанию и требуется для явных логических операторов. Проверки компилятора и источника общие. Выбор формата включён в cache key и recording; старые записи без поля воспроизводятся как IR. Для настроенного провайдера: `AH_LLM_PERCEPTION_FORMAT=roles`; для локального benchmark: `--perception-format roles`.
